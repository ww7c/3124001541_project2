# 项目简介

实现一个自动生成小学四则运算题目的命令行程序。

程序能够根据用户指定的题目数量和数值范围，随机生成包含整数、真分数和带分数的四则运算题目，并计算每道题目的正确答案。同时，程序支持读取用户填写的答案，与标准答案进行逐题比较，并生成批改结果。

项目主要用于实现小学四则运算题目的自动生成、计算和批改。

## 主要功能

### 1 随机生成题目

程序可以根据指定参数随机生成四则运算题目。

支持的运算符：

* `+` 加法
* `-` 减法
* `×` 乘法
* `÷` 除法

### 2 计算题目答案

程序在生成表达式的同时计算表达式的正确结果，并将结果保存到答案文件中。

### 3 答案批改

程序支持读取题目文件、标准答案文件和用户答案文件，对用户答案进行逐题比较。

### 各模块功能

| 模块                  | 功能                  |
| ------------------- | ------------------- |
| `main.cpp`          | 程序入口，处理命令行参数并调用其他模块 |
| `random_num`        | 随机生成自然数             |
| `random_operator`   | 随机生成四则运算符           |
| `Fraction`          | 实现分数的存储、约分和四则运算     |
| `random_Fraction`   | 随机生成整数、真分数和带分数      |
| `random_expression` | 生成完整四则运算表达式并计算结果    |
| `check`             | 检查用户答案并生成批改结果       |

## 命令行参数

程序通过命令行参数控制运行方式。

### 生成题目

使用：

```text
Project2.exe -n 10 -r 10
```

### 5.3 答案批改

使用：

```text
Project2.exe -e proper_answerfile.txt -a user_answerfile.txt
```
